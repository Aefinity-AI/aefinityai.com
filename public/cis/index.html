CIS-2 · open standard

CIS-2 is an open specification with verifiers in C and Rust for bit-exact fp32 inference, with public conformance vectors. In our own runs, one digest reproduced on AVX2 and scalar x86, an AVX-512-capable cloud CPU (generic build, self-check only), an aarch64 phone and a Tesla P100 GPU.

What a fixed baseline makes possible

  • The baseline for every AI test harness

    A non-changing, per-hardware reference that evaluations, safety tests, red-teaming and regression suites run against, so drift in results means drift in the model, not noise.

  • Hardware and cloud qualification

    Prove a new server, GPU, driver or cloud instance produces identical results before it goes into service.

  • Model supply-chain integrity

    Detect silent changes to model weights.

    L06 · One flipped bit in the weights: which checks notice? L07 · Realistic edits to the embedding table, including one hidden row

  • Audit and dispute evidence

    Replay a run and show the record matches, bit for bit.

  • Vendor verification

    Check that an AI provider ran the model and settings it says it ran.

  • Reproducible research and evaluation

    Results anyone can re-run exactly.
